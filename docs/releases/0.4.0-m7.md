## Size result and shrinker decision

The M6 release baseline was 45,339,694 bytes. M7 is smaller by 14,955,872 bytes, or 32.99%, and is
9.62 MB below the 40 MB decimal release budget. The reduction comes from a deterministic 3,823-entry
class-only API 24 compiler stub in place of the complete platform archive.

R8 compat mode and resource shrinking were evaluated rather than silently skipped. R8 generated
144 broad missing-JDK/compiler `-dontwarn` suggestions; accepting them would make the embedded
compiler's reflection and service-loading boundaries unverifiable. Both options therefore remain
disabled. The measured top-ten APK entries and full rationale are in the
[size baseline](../perf/size-baseline.md).

## Local release gates

The release commit completed these commands in offline mode:

```powershell
.\gradlew.bat -p build-logic/platform-versions test --offline --console=plain
.\gradlew.bat :app:verifyPinnedInputs :app:verifyPinnedInputsFailurePath :app:verifyPinnedInputsWiring :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease :app:assembleDebugAndroidTest :m7-harness:assembleDebug :m7-harness:lintDebug --offline --console=plain
```

- Unit tests: 124 tests in 40 XML suites; 0 failures, 0 errors, 0 skipped.
- Frozen Protocol: valid-input, one-byte-corruption, and assemble-wiring gates passed.
- Assemblies: debug, host-aligned release, debug Android-test, and M7 harness APKs passed.
- Lint: the application reported no new issues with 13 reviewed baseline entries; the new harness
  reported no issues.
- Final aggregate: `BUILD SUCCESSFUL` in 5 minutes 23 seconds, 193 actionable tasks (68 executed,
  12 from cache, 113 up-to-date).
- Static script/workflow checks: PowerShell parser, Bash `-n`, and `actionlint` all passed.

The tag was then exported with `git archive`, extracted to an isolated fixed directory, and given
only temporary copies of the ignored trusted signing inputs. The repository-local platform plugin
test passed in 50 seconds with all seven tasks executed. The full aggregate above passed again in
5 minutes 34 seconds with 193 actionable tasks (167 executed, 22 from cache, 4 up-to-date) and
124/124 unit tests. Both Lint reports were clean. The archive-built release was 30,383,754 bytes;
its hash differs from the canonical clone-built APK because a source archive has no `.git`
directory for AGP version-control metadata. The entire audit directory, including the two temporary
signing copies, was removed after verification.

public APK, or AutoJs6 official schema-v2 index update was created. Private commits, tags, Actions,
and Roadmap links function normally; public distribution remains a separate future visibility
