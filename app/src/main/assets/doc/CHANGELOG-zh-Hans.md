# v0.5.0-m8

###### 2026/08/25

* `优化` 包名策略文案更明确: 仅支持普通 ASCII 标识符, 拒绝时给出稳定可读的提示而非误导性报错
* `优化` 诊断信息按 UTF-8 预算截断且只在 Unicode 码点边界截断, 不会出现半个 emoji

# v0.4.0-m7
